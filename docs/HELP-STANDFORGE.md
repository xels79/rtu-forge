# Справка: Stand Forge, IDD, полив и давление

**Назначение:** ручная работа с реле/аналоговыми выходами, диагностика частотников IDD и датчиков давления, управление циклом полива. Действующие ограничения и проверки задаются в `stand.ini`.

## Запуск
```powershell
standforge --help
standforge --port COM7 --baudrate 9600
```

## Читающие команды (начните с них)
```text
status
idd 7 status
idd 8 status
idd all monitor
ai
ai types
pressure
start check 1 1 broth 29
```
`start check` проверяет готовность без открытия клапанов, запуска двигателей и записи регистров. Частота задаётся **в Гц**; прежние сценарии с числом-процентом надо обновить.

## Ручные команды (меняют оборудование)
```text
on 9
off 9
output temperature 50
```
`output` по-прежнему принимает **проценты**. Выполняйте только при проверенном назначении каждого реле/канала.

## Пуск и останов
```text
start check 1 1 broth 29
start step 1 1 broth 29
stop
emergency-stop
reset fault
```
`start step` требует отдельного Enter перед каждым действием. Разрешение автоматики и подтверждения оборудования по умолчанию не активны; без корректного `stand.ini` запуск блокируется. Во время цикла оставайтесь в **том же процессе** для команды `stop`.

## Выбор насоса
```text
start check 2 1 broth 29 --pump 1
start step 2 1 broth 29 --pump 1
```
Указанный насос используется независимо от стеллажа; адрес IDD и FWD берутся из настройки маршрута. Принятый пуск определяет маршрут останова.

## IDD
```text
idd 7 setup
idd 7 feedback
idd 7 monitor
idd 7 frequency 29
idd 7 configure --confirm
idd 7 configure manual --confirm
```
`frequency` и `configure` **пишут в устройство**; `status/setup/monitor/feedback` используются для диагностики. Значения Pb05/Pb06 и карты PA должны соответствовать фактическому приводу.

## Безопасность
Нельзя считать подтверждение реле подтверждением физического положения клапана. Не подключайте второго независимого master к активной RS-485 шине. Для давления обязательны независимые аппаратные ограничения; `raw=0` не всегда доказывает исправность датчика. При признаках аварии применяйте установленную аппаратную процедуру останова.
