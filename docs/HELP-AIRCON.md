# Справка: Hisense Aircon / ONOKOM

**Назначение:** отдельный интерфейс для Hisense AUC-18HR4SAA1 с шлюзом ONOKOM HS-A6 / HS-6-MB-B. Программа запускается **через `rtuforge aircon`**, а не через отдельный исполняемый файл.

## Демонстрация, без железа
```powershell
rtuforge aircon --demo
```

## Чтение диагностики (без управляющих записей)
```powershell
rtuforge --port COM7 --baudrate 9600 --bytesize 8 --parity N --stopbits 2 aircon diag
```

## Подключение к оборудованию
```powershell
rtuforge --port COM7 --baudrate 9600 --bytesize 8 --parity N --stopbits 2 aircon
```
COM7 и ID устройства служат примерами. Укажите данные вашего ONOKOM. Сначала используйте `diag`, сверяйте CRC и версию шлюза.

## Управление и конфигурация
В интерактивном приложении доступны `on`, `off`, `temp`, `mode`, `fan` (изменяют состояние кондиционера) и `set <имя> <значение>` для сохранения параметров в отдельный `aircon.ini`. Управляющие записи не выполняются до явной команды оператора. CLI-параметры порта имеют приоритет перед конфигурацией.

Полная карта регистров, команды, диагностика и подключение: [AIRCON-RU.md](AIRCON-RU.md).
