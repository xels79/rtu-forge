## 2. Протокольная валидация

- [x] FC01 / FC02:
  - `byte_count == 1`;
  - точная длина кадра;
  - плохой CRC не считается устройством.
- [x] FC03 / FC04:
  - `byte_count == 2`;
  - точная длина кадра;
  - malformed/truncated response не считается устройством.
- [x] Exception response:
  - slave ID совпадает;
  - function = request function `| 0x80`;
  - CRC корректный;
  - длина exception frame точная;
  - корректный exception response считается найденным устройством.
- [x] Wrong slave / wrong function / serial noise не считаются найденным устройством.
