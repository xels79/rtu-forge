# RTU Forge — TODO `scan` на 28.08.2026

Ветка: `feature/console-ux`

Цель: закончить проверку `scan` и закрыть оставшиеся замечания без смешивания с установочными изменениями.

## 1. CRC blocker

- [ ] Заменить для `scan` `crc_mode_override="auto"` на `crc_mode_override="append"`.
- [ ] Не менять семантику `runtime.crc_mode` для обычного `send`.
- [ ] Зафиксировать контракт: `build_probe()` всегда возвращает Modbus-запрос без CRC.
- [ ] Добавить regression test на CRC collision:
  - probe: `01 03 BF 62 00 01`;
  - сам 6-байтовый probe случайно проходит `has_valid_crc()`;
  - scanner всё равно обязан передать `crc_mode_override="append"`;
  - фактический TX должен содержать добавленный CRC.
- [ ] Обновить существующие scan tests: ожидать `"append"`, а не `"auto"`.

## 2. Протокольная валидация

- [ ] FC01 / FC02:
  - `byte_count == 1`;
  - точная длина кадра;
  - плохой CRC не считается устройством.
- [ ] FC03 / FC04:
  - `byte_count == 2`;
  - точная длина кадра;
  - malformed/truncated response не считается устройством.
- [ ] Exception response:
  - slave ID совпадает;
  - function = request function `| 0x80`;
  - CRC корректный;
  - длина exception frame точная;
  - корректный exception response считается найденным устройством.
- [ ] Wrong slave / wrong function / serial noise не считаются найденным устройством.

## 3. Аргументы `scan`

- [ ] Проверить:
  - `scan`;
  - `scan 7`;
  - `scan 1 32`;
  - `scan 1 247 --timeout 200`;
  - `scan 1 32 --function 04`;
  - `scan 1 32 --function 03 --address 65`;
  - `scan 1 32 --function 03 --address 0065`;
  - `scan 1 32 --function 03 --address 0x0065`.
- [ ] Проверить ошибки:
  - ID `< 1`;
  - ID `> 247`;
  - start > end;
  - timeout `<= 0`;
  - function вне `01..04`;
  - address вне `0..65535`;
  - неизвестный flag;
  - flag без значения.

## 4. Live progress

Ручная проверка в Windows Terminal.

- [ ] Строка progress одна и обновляется на месте.
- [ ] Строка не прыгает при:
  - `009 -> 010`;
  - `099 -> 100`.
- [ ] Формат содержит fixed-width поля:
  - index;
  - total;
  - slave ID;
  - found count.
- [ ] Найденные устройства печатаются выше Live-строки.
- [ ] HEX RX найденного устройства не получает случайную Rich-подсветку отдельных байтов.
- [ ] После окончания scan Live-строка корректно исчезает.
- [ ] После `Ctrl+C` терминал и приглашение `rtu>` остаются визуально целыми.

## 5. Ctrl+C и scripts

- [ ] Standalone `scan`: Ctrl+C останавливает только scan и возвращает shell.
- [ ] `scan` внутри stored script:
  - scan останавливается;
  - оставшиеся строки текущего script не выполняются;
  - вложенный `run script` корректно протаскивает interruption вверх;
  - RTU Forge shell не завершается;
  - traceback отсутствует.
- [ ] Regression test: команда после `scan` не выполняется после Ctrl+C.
